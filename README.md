# URL Shortener

REST API сервис для сокращения ссылок, написанный на **Go**
с использованием **PostgreSQL**, автоматических миграций и контейнеризации.

Это мой первый пет-проект после начала изучения Go.
И целями этого пет-проекта лично для меня были: 
1. Работа с чистой многослойной архитектурой, где все разделено по слоям.
2. Разобраться как можно связать сервис и БД
3. Разобраться с версионированием и миграциями
4. Изучение докера: dockerfile, docker-compose


## Стек технологий

* **Язык:** `Go`
* **БД:** `PostgreSQL`
* **Драйвер БД:** `jackc/pgx/v5`
* **Миграции:** `golang-migrate/migrate/v4`
* **Конфигурация:** `godotenv`
* **Контейнеризация:** `Docker, Docker Compose`

## Архитектура

Проект построен по принципу многослойной архитектуры:
```text
cmd/api/main.go        #точка входа, зависимости
internal/
    -config/           #Загрузка конфигурации
    -handler/          #HTTP транспорт(статусы, парсинг JSON)
    -service/          #Бизнес-логика(Валидация URL, генерация кодов, TTL)
    -repository/       #Доступ к данным
    -models/           #доменные сущности
migrations/            #Версионированные SQL-миграции
```
## Что реализовано
1. Генерация кодов: для генерации использовал crypto/rand, длина кода 8 символов. 
На данный момент, защиты от коллизий нет, но вероятность их появления очень мала.
2. Безопасность: Время жизни ссылки сделано через указатели, приложение не упадет, если пользователь ничего не введет в это поле.
Также есть защита от SQL-инъекций через плейсхолдеры($1).
3. Двухэтапная сборка: сборка бинарника на первом этапе, потом его запуск на чистом образе alpine.

## Быстрый запуск
Для быстрого запуска сервиса, нужен Docker и Git.
1. Клонируем репозиторий.
```bash 
git clone https://github.com/UnkwzX/url-shortener.git
cd url-shortener
```
2. Запуск через Docker Compose:
```bash
docker compose up --build
```
## Примеры использования 
Тут можно использовать как Bash, так и более удобный Postman.
### 1. Создание короткой ссылки

**Запрос:**
```bash
curl -X POST http://localhost:8080/links -H "Content-Type: application/json" -d '{"url": "https://ya.ru", "ttl_hours": 24}'
```
**Ответ:**
```bash
{"code":"n8h7IC73","short_url":"http://localhost:8080/n8h7IC73"}
```


### 2. Переход по короткой ссылке
**Запрос:**

```bash
curl -v http://localhost:8080/n8h7IC73
```

**Ответ:**

```text
* Request completely sent off
< HTTP/1.1 302 Found
< Content-Type: text/html; charset=utf-8
< Location: https://ya.ru
< Date: Thu, 27 Aug 2026 14:13:30 GMT
< Content-Length: 36
<a href="https://ya.ru">Found</a>.
```
Также можно просто перейти по сгенерированной ссылке в браузере и будет редирект на страницу.
